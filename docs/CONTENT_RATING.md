# Content Rating (IARC questionnaire) — Draft answers

Complete in Play Console → App content → Content ratings. Expected result: **Everyone / PEGI 3**.

- Category: **Game**.
- Violence: **Cartoon/fantasy only** — stylized monsters battle with no blood, gore, or
  realistic violence; no humans harmed. (Answer "mild/cartoon fantasy violence" if asked;
  most questionnaires still return Everyone.)
- Sexual content: **None.**
- Nudity: **None.**
- Profanity: **None.**
- Drugs/alcohol/tobacco/gambling: **None.** (No loot boxes with real-money randomization;
  daily rewards are deterministic and free.)
- User-generated content / social / chat: **None** (single-player, offline).
- Shares user location: **No.**
- In-app purchases: **No** for the recommended offline build (see Data Safety); if enabled,
  answer **Yes** (digital goods).
- Data collection: per Data Safety draft.

Target rating: **ESRB Everyone / PEGI 3 / USK 0 / IARC 3+.**
